FILES
- Guia-visual-Rural-Conecta.pdf: color roles, name colors, sizes,
  practical settings, current theme limits, and contrast measurements.
- logos-png/: white RGBA PNGs with actual transparency at 48, 64, 96,
  128, and 256 px, plus the original-size 193 px white version.
- previa-aplicacao.png: application preview, not a transparent logo.
- paleta-referencia.json: design reference only. Do not import this as
  Hublink configuration; it contains no catalog, account or link data.
- SHA256SUMS.txt: integrity checksums of the files in this kit.

SOURCE AND GEOMETRY
Both provided PNGs were byte-identical (193 x 193 px).
The final white asset reuses the original alpha mask. Every RGB channel
is 255; transparency and internal cutouts are retained. The native
193 px file has exactly the same alpha values as the source.
Normalized square versions center the original 140 x 183 px visible
shape without stretching it, at about 94% of the canvas height.
The 256 px output is a raster resample, not a vector reconstruction.
The 48 px file is for compact uses; the full detailed mark may lose
legibility at favicon sizes. No simplified favicon was invented.

IMAGE WORKFLOW
Built-in image_gen was used for an initial recolor. That generated
candidate changed fine details and was rejected. The delivered PNGs
were finished using Sharp with the original alpha for exact geometry.
Prompt used: Recolor the supplied icon to pure white #FFFFFF. Preserve
all rays, trees, tower, house, field stripes and cutouts. Keep a genuinely
transparent background. Do not redesign, add text, gradients or shadows.

SCOPE
This is a downloadable asset and design package. No application source,
saved identity, database, account, provider or running service was changed.
The dark design direction requires theme-specific styling and a logo
tile independent from the accent. Current custom colors are shared
across themes; switching the current accent to lime would also make
the white-logo tile lime and reduce contrast.
